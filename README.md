🏝️ Book Your Paradise

A MERN stack accommodation booking platform inspired by Airbnb, built for users to explore, book, and manage stays seamlessly.

🚀 Overview

Book Your Paradise is a full-stack web application for booking and hosting accommodations.
Users can sign up, list properties, browse stays, and make bookings through a simple, responsive interface.

✨ Key Features

🔐 Secure Authentication: JWT-based login/signup with bcrypt password hashing.

🏠 Listings Management: Hosts can add, edit, and delete property listings.

📅 Bookings: Guests can search, view, and book available stays.

🧾 Edit Bookings: Modify booking details such as dates or guests.

🧱 MVC Architecture: Clean separation of logic, data, and UI for scalability.

🧰 Tech Stack

Frontend: React.js, TailwindCSS
Backend: Node.js, Express.js
Database: MongoDB
Hosting: Vercel, AWS S3
